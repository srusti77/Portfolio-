# Srusti Ponnaganti Portfolio

React + Vite frontend with the sample portfolio's CMS-style editing flow and an Express backend using local JSON persistence.

## Run

### Backend
```bash
cd backend
npm install
npm run dev
```
Backend: http://localhost:5000

### Frontend
Open a second terminal:
```bash
cd client
npm install
npm run dev
```
Frontend: http://localhost:5173

## Admin
Admin Login password: `srusti123`

After logging in, edit fields directly on the portfolio and use **Save** to persist changes to `backend/data/portfolio.json`.
